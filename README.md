# Site Consciência Negra — Katherine Johnson (NASA)

Projeto web moderno e interativo desenvolvido em **HTML5**, **CSS3** e **JavaScript** em alusão ao **Dia da Consciência Negra**, celebrando o legado de **Katherine Johnson** na tecnologia aeroespacial.

## Como abrir no VS Code
1. Extraia este arquivo `.zip`.
2. Abra a pasta no **Visual Studio Code**.
3. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server** (ou abra diretamente no navegador).
